# Система разграничения прав доступа 

## Роли
- **admin** – полный доступ: просмотр всех пользователей, изменение ролей
- **user** – базовый доступ: только работа со своим профилем

## Таблицы БД
- `users` – содержит `role_id` (внешний ключ)
- `roles` – `id`, `name` (admin/user), `description`

## Принцип проверки
- Запросы без токена -> 401
- Запросы с токеном, но недостаточными правами -> 403
- Для админа эндпоинты помечены `require_role("admin")`

## API для управления правами (только админ)
| Метод | Путь | Описание |
|-------|------|-----------|
| GET | /users | Список всех активных пользователей |
| PUT | /users/{id}/role?role_name= | Изменить роль пользователя |
