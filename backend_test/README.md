# Название проекта

Приложение для управления пользователями с разграничением прав доступа

## Функционал

- Регистрация, аутентификация и управление профилем пользователя.
- Разграничение прав: обычные пользователи и администраторы.
- Администратор может просматривать список всех пользователей и назначать им роли.
- Безопасное хранение паролей и JWT-токенов.
- Список проектов (бизнес-логика)

## Технологии

- **FastAPI** — создание API.
- **SQLAlchemy** — работа с базой данных.
- **SQLite** — база данных.
- **JWT** — аутентификация пользователей.

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/tatarus/my_portfolio/backend_test.git
   cd backend_test/
   ```
2. **Создайте и активируйте виртуальное окружение**
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # Для Linux
    .venv\Scripts\activate   # Для Windows
    ```
3. **Установите зависимости**
    ```bash
    pip install -r requirements.txt
    ```
5. **Инициализируйте БД**
    ```bash
    python init_db.py
    ```
4. **Запустите сервер**
    ```bash
    uvicorn app.main:app
    ```
