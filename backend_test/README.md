# Название вашего проекта

Gриложение для управления пользователями с разграничением прав доступа (RBAC)

## Функционал

- Регистрация, аутентификация и управление профилем пользователя.
- Разграничение прав: обычные пользователи и администраторы.
- Администратор может просматривать список всех пользователей и назначать им роли.
- Безопасное хранение паролей (хеширование) и JWT-токенов.

## Технологии

- **FastAPI** — создание API.
- **SQLAlchemy** — работа с базой данных.
- **SQLite** — база данных (укажите вашу).
- **JWT** — аутентификация пользователей.

## Установка и запуск

Инструкция ниже рассчитана на пользователей, которые знакомы с командной строкой.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/tatarus/my_portfolio/backend_test.git
   cd backend_test/
   ```
2. **Создайте и активируйте виртуальное окружение**
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate  # Для Linux/macOS
    .venv\Scripts\activate   # Для Windows
    ```
3. **Установите зависимости**
    ```bash
    pip install -r requirements.txt
    ```
5. **Инициализация БД**
    ```bash
    python init_db.py
    ```
4. **Запустите сервер**
    ```bash
    uvicorn app.main:app
    ```
